# 研究方法论

本项目的数据组织方法直接学习自编程随想的 [zhao 项目《太子党关系网络》](https://github.com/programthink/zhao)（2016–2018，GPL-3.0），
并在“可验证性、时效性、结构化、自动化”四个方向上加以改进。

## 1. zhao 项目做对了什么

通读其仓库（862 个人物、9 家公司、165 个家族、14 张分组关系图）后，提炼出的核心方法：

| 环节 | zhao 的做法 | 价值 |
|---|---|---|
| 圈定对象 | `graph.yaml` 按“第 1–5 代高官、开国元帅/大将/上将/中将/少将、中共早期高官、前朝名人”分组列出家族 | 先定边界再挖细节，避免无穷扩张；分组本身就是权力结构 |
| 一人一档 | `person/<姓名>/brief.yaml`：常用名、曾用名、性别、生卒年、几行简述、链接 | 人物是图的节点，独立成档便于多人协作、增量更新 |
| 一族一档 | `family/<家族>.yaml`：以家族中“最牛”的人命名；`inner`=血亲核心，`outer`=非血缘（姻亲、关联公司） | 家族是权贵的基本单位；核心/外围之分对应“权力继承”与“利益输送”两类关系 |
| 三元组关系 | `[甲, 乙, 称谓]`，称谓尽量一两个字（长子、妻、秘书、早期股东） | 极简、可读、可机器处理 |
| 以姻亲和资本为桥 | 公司也是节点（如“万达集团”的早期股东中有多个权贵亲属）；联姻把家族连成网 | 真正有情报价值的是跨家族、跨政商的边 |
| 来源优先级 | 维基百科 > 国际权威媒体（纽时、华日、FT）> 官方网站/百度百科（仅限客观事实） | 可信度意识 |
| 生成物 | Python + Graphviz 把 YAML 编译成 PDF/JPG 大图 | 数据与呈现分离 |

## 2. 本项目的改进

| 问题（zhao 的局限） | 改进 |
|---|---|
| 862 人中仅 116 人有链接，**关系本身没有来源** | 每个实体、每条关系都可带 `sources`；文件级默认来源被继承；精编层缺来源会告警 |
| 事实与传闻混在一起（如“习明泽—梁治中”婚姻传闻） | 五级 `confidence`（确证/报道/指控/有争议/传闻）；传闻以虚线显示、可按可信度过滤 |
| 称谓是自由文本，机器无法区分方向与语义 | 受控关系词表（`vocab.ts`）：类型+方向+类别+路径权重；称谓保留为 `label` |
| 只有生卒年和几行简述，没有时间维度 | 结构化 `positions`（职务、机构、起止时间）、`since/until`、`status`（在任/落马/羁押/流亡…） |
| 数据停在 2018 年 | 连接器（Wikidata 等）可随时重跑；`todo` 命令按影响力×缺口给出复核清单；AI 代理按 AGENTS.md 流程持续更新 |
| 只覆盖中共太子党 | 中美两国、政商军学媒全领域；跨国“桥梁”单独建档 |
| 静态大图，看不清也查不了 | 交互式：全局网络、N 跳关系网、族谱布局、六度路径、档案面板、实时搜索（含拼音首字母） |
| 只能导出 PDF/JPG | 导出 CSV、GraphML、GEXF、Neo4j Cypher、Graphviz DOT（致敬 zhao）、JSONL（RAG）、Markdown |

## 3. 研究循环（每个人/家族都按此执行）

1. **圈定**：此人是否在覆盖范围（tier 1–5）？属于哪个圈子（家族/派系/机构班子/案件）？
2. **建档**：基本身份（姓名各语种、别名、生卒、籍贯、国籍）→ 履历（按时间）→ 当前状态。
3. **挖亲属**：父母、配偶（含前配偶）、子女、兄弟姐妹 → 子女的配偶及其家族（姻亲是跨家族的桥）。
4. **挖资本**：本人及亲属任职/持股的公司；工商登记、上市公司公告、离岸解密、调查报道。
5. **挖人脉**：秘书（中国政坛“秘书帮”）、提拔者与门生、同学、同乡、同僚、金主（美国政治献金）。
6. **交叉验证**：每条关系找第二个独立来源；标注可信度；矛盾信息标 `disputed` 并在 note 中说明。
7. **时间标注**：任免、婚姻、持股都写起止时间；落马写清“立案—免职—开除—判决”时间线。
8. **复核**：重大事件（全会、换届、大选、调查报道）后回到第 1 步。

## 4. 圈定对象：本项目的“代际表”

| 层级 | 中国 | 美国 |
|---|---|---|
| T1 | 政治局常委、军委主席/副主席、国家主席/副主席 | 总统、副总统、国务卿、财长、防长、美联储主席、众议长、参院多数党领袖、首席大法官；顶级富豪（≥1000 亿美元） |
| T2 | 政治局委员、书记处书记、副总理、国务委员、军委委员、上将 | 内阁成员、白宫幕僚长/国安顾问、最高法院大法官、身家≥200 亿美元富豪、主要传媒/科技掌门 |
| T3 | 省级党委书记、部长、知名红二代/红三代企业家 | 参议员、州长、内阁级官员、重要金主 |
| T4 | 中将、副部级、中型企业家 | 众议员、亲属中的公众人物 |
| T5 | 其他亲属与关联人 | 其他亲属与关联人 |

Wikidata 预设（`tools/cli/src/connectors/wikidata.ts`）就是这张表的可执行版本。

## 5. 来源与可信度判定

- `confirmed`：官方文件/公报（新华社通报、中纪委通报、政府任免、法院判决、SEC 文件、国会记录），或 ≥2 家权威媒体独立报道。
- `reported`：单一权威媒体或维基百科（有引用）。
- `alleged`：调查报道、诉讼、起诉书中的指控（未经判决）。
- `disputed`：存在相互矛盾的权威说法。
- `rumor`：网络/海外中文媒体的未证实说法——可以作为线索收录，但必须标注。

> 注意：海外反共媒体（如大纪元、新唐人）与中国官方媒体都存在立场偏差。前者的独家爆料一般只标 `rumor` 或 `alleged`，
> 后者对本国官员负面信息的缺失不等于不存在。
